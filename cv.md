## Proyectos Destacados

### Exelcior Apolo - Transformador Inteligente de Excel

**Repositorio:** https://github.com/stredes/exelcior_apolo

Aplicacion de escritorio en Python para transformar, validar e imprimir archivos Excel de forma automatizada, optimizada para flujos logisticos, comerciales, inventario y etiquetas.

- Autodeteccion de archivos Excel en carpeta de descargas por modo de operacion.
- Reglas configurables para eliminar columnas, sumar datos, conservar formatos y ajustar transformaciones.
- Vista previa interactiva, historial persistente, logs integrados, exportacion a PDF e impresion multiplataforma.
- Tecnologias: Python 3.12, Tkinter, pandas, openpyxl, SQLAlchemy, SQLite, ReportLab, LibreOffice/Excel COM.
